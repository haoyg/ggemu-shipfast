# Sloop Web Directory submission — POKOPIE

Prepared for <https://sloop.nz/submission/>.

- **Website title:** POKOPIE — Browser Retro Gaming & Compatibility Check
- **Website URL:** https://pokopie.com/en/ps1-compatibility
- **Category/type:** Retro gaming and browser-based compatibility tool
- **Website directory:** Modern Website Directory
- **Description:** POKOPIE provides a browser-side PS1 compatibility check for people exploring web-based retro gaming. It tests WebAssembly, WebGL 2, IndexedDB, gamepad, fullscreen, and shared-memory support locally in the browser, then explains the result and its limits. The site also publishes practical guides on retro platforms, controllers, and browser saves.

The Sloop submission page requires reCAPTCHA. This copy avoids claims about ROM availability and directs visitors to the compatibility resource rather than a game catalogue.
