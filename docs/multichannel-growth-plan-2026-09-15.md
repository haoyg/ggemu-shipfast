# POKOPIE 多渠道推广计划

状态：执行草案。目标是在不购买外链、不批量灌水的前提下，为核心游戏页带来相关访问、品牌搜索、自然引用和回访。

## 30 天执行排期

### 第 1 周：做出可以反复分发的内容资产

1. 录制一条 60–120 秒横版视频：进入游戏、点击启动、F/J 红音、D/K 蓝音、切换歌曲分类、开始第一首歌。
2. 同一素材裁成 3 条竖版视频：红蓝音键位、选曲快捷键、新手常见卡点。
3. 制作一张 1200×630 的 Taiko Web 键位图，页面、视频封面和社区帖子统一使用。
4. 将现有游戏详情内容扩充为独立攻略页，覆盖：`taiko web controls`、`taiko web keyboard`、`taiko web not loading`、`taiko web latency`。
5. 给视频页或含视频的攻略页加入稳定缩略图、`VideoObject` 数据和视频 sitemap 条目。

### 第 2 周：发布并获取第一轮真实反馈

1. 先向 `r/taikonotatsujin` 版主发送已准备的询问信；只有得到许可后才发布资源帖。
2. 发布 YouTube 主视频。说明栏首屏放规范游戏页链接；Shorts 描述中的普通 URL 不可点击，因此 Shorts 用频道资料链接或关联长视频承接。
3. 在 TikTok、Instagram Reels 和 YouTube Shorts 发布同一素材的不同剪辑，不逐字复制标题。
4. 整理 20 个近 90 天仍活跃的小型节奏游戏频道，优先选择已有 Taiko、osu!taiko 或浏览器节奏游戏内容的创作者。
5. 给其中 10 位发送个性化试玩邀请，不要求正面评价、不购买 dofollow 链接，并披露站点归属。

### 第 3 周：扩大可引用内容

1. 发布第二条搜索视频：`Taiko Web keyboard latency test and browser setup`。
2. 发布一篇对比型攻略：键盘布局、浏览器焦点、音频延迟和首曲设置，不虚构设备测试结果。
3. 给键位图提供下载和嵌入代码，嵌入内容保留可见来源链接，不强制隐藏链接或使用关键词锚文本。
4. 联系已经写过 Taiko Web 操作教程的独立博客，指出攻略中缺失或过时的信息，提供键位图作为补充资料。
5. 首页增加“本周最受欢迎”和“最近玩过”，提高社区流量进入后的第二次游戏点击。

### 第 4 周：复盘并复制胜出渠道

1. 比较各渠道的引荐会话、游戏启动率、平均互动时长和 7 日回访，不只统计外链数量。
2. 在 GSC 比较 Taiko 页面发布前后等长窗口的展示、点击、CTR 和平均排名。
3. 若视频带来的启动率高，下一轮制作 Geometry Dash Advance；若攻略搜索增长更快，继续覆盖 Taiko 长尾问题。
4. 只有某种内容在英文渠道验证有效后，才制作日文版本。
5. 停止连续两轮没有相关访问或互动的渠道。

## 各渠道具体做法

### 视频

- YouTube 主视频承担可搜索内容和可点击链接；Shorts、TikTok、Reels 承担发现流量。
- 每条视频只解决一个问题，开头 3 秒直接展示游戏和键位，不先介绍网站。
- 使用录屏、字幕和真实操作声；页面链接放在 YouTube 长视频说明栏与频道资料页。
- 在站内攻略页嵌入主视频，使页面同时覆盖文字和视频搜索。

### 创作者合作

- 目标不是大型频道，而是 500–20,000 订阅、近期仍发布节奏游戏内容的小频道。
- 邀请文只说明为什么内容与对方频道相关，提供试玩页、键位说明和截图素材。
- 允许对方自由评价；如果提供报酬、礼品或其他利益，要求按平台规则披露。
- 不要求指定锚文本，也不把链接是否 dofollow 作为合作条件。

### 可引用资产

- 键位图：桌面版和手机版各一张，标出红音、蓝音、选曲和模式快捷键。
- 故障排查表：黑屏、无声、键盘无响应、焦点丢失、移动设备限制。
- 延迟测试说明：解释浏览器、蓝牙音频和显示器延迟，不发布没有实测支持的结论。
- 嵌入卡片：标题、缩略图、操作摘要和一个规范来源链接。

### 站内增长

- 在每个核心游戏页展示 3 个真正相关的游戏，而不是随机推荐。
- 记录最近玩过，方便用户返回；无需登录即可使用本地存储。
- 游戏结束或退出播放器后显示“再玩一款”入口。
- 用每周精选邮件或 Web Push 通知已有用户；必须由用户主动订阅，并控制在每周一次以内。

### 游戏目录和分发平台

- itch.io、Newgrounds 等平台更适合原创或已取得完整再分发权的 HTML5 游戏。
- POKOPIE 当前页面如果只是嵌入第三方播放器，不应直接打包上传，也不应声称自己是游戏作者。
- 在权利状态未确认前，只推广原创攻略、视频和操作图，不把第三方游戏文件提交到目录。

## 本轮不执行

- 购买外链、站群链接、批量目录提交和自动化评论。
- 在多个 subreddit 同日复制同一帖子。
- 用与游戏无关的社区换取流量。
- 未确认权利时向 itch.io、Newgrounds 或其他游戏平台重新上传游戏文件。
- 把 Shorts 描述中的 URL 当作主要点击入口。
