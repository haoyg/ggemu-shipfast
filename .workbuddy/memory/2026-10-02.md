- 判断"重复代码"前先看行数，7 行的路由可能是重定向桩而非重复实现。

## 优化落地执行（同一天下午）

按 P0 → P1 顺序实际改了代码。

### 1. 字体子集化（已完成，已验证）

- 发现字体里塞了 **11172 个韩文字符**（站点只有中/英/日三语），还含盲文 256、西里尔 153、康熙部首等无用区块
- 只删韩文仅省 15%，大头是 19214 个汉字 —— 真正的杠杆在于限制汉字范围
- 实测分档：GB2312 全集 7622 cps → 178KB；GB2312 一级字 4536 cps → 110KB
- **选定 GB2312 全集方案**：`645KB + 653KB → 197KB + 199KB，合计省 902KB（降到 30.5%）**
- 没选激进的一级字方案，因为 `h1` 在详情页渲染的是上游 API 返回的游戏名（任意汉字），子集过窄会缺字
- 原字体移到 `tools/fonts/source/` 并保留，子集脚本固化到 `tools/fonts/subset.py` 可重复执行
- **验证结果**：源码中实际使用的 1300 个 CJK/假名/全角字符，子集后**新增缺字 0 个**（原本就缺的 3 个：U+3040、焋、鿿）

### 2. 缓存头（已完成）

`public/_headers` 补 `/fonts/*` 和 `/platform-icons/*`，均为 `max-age=604800, stale-while-revalidate=2592000`（文件名无 hash，不用 immutable）
